# OASIS INFOBYTE — Java Development Task: Number Guessing Game

## Features
- Random number generation
- Easy, Medium, and Hard difficulty levels
- Limited attempts and higher/lower hints
- Input validation
- Score tracking and replay option

## Requirements
- JDK 8 or newer
- Terminal / Command Prompt

## Run
Open a terminal in this folder and run:

```bash
javac src/NumberGuessingGame.java
java -cp src NumberGuessingGame
```

## How to play
1. Choose a difficulty level.
2. Enter a whole-number guess within the shown range.
3. Follow the higher/lower hints.
4. Guess the number before attempts run out to earn points.
5. Choose whether to play another round.
